1. Introduction to Seaborn

Seaborn is a high-level statistical visualization library built on top of Matplotlib. It provides a beautiful default aesthetic, integrates tightly with Pandas DataFrames, and offers specialized plot types for exploring relationships, distributions and categorical data.

Why Seaborn?

  • Attractive default themes and color palettes
  • Functions that automatically compute and show statistical estimates
  • Close integration with Pandas (works directly with DataFrames and Series)
  • Convenient multi-plot grids (FacetGrid, PairGrid, JointGrid)
  • Still fully compatible with Matplotlib for fine-grained control

3. Themes & Styles

Seaborn controls the look of Matplotlib figures through themes.

python
# Main theme setter
sns.set_theme(style='darkgrid',      # darkgrid | whitegrid | dark | white | ticks
              palette='deep',        # or a custom palette
              font='sans-serif',
              font_scale=1.1,
              rc={'figure.figsize': (8, 5)})

# Individual controls
sns.set_style('whitegrid')
sns.set_context('notebook')          # paper | notebook | talk | poster
sns.despine(left=True, bottom=False) # remove spines
sns.despine(offset=10, trim=True)

5. Relational Plots

Show relationships between two (or more) quantitative variables.

python
# Scatter plot
sns.scatterplot(data=df, x='total_bill', y='tip',
                hue='sex', style='time', size='size',
                sizes=(20, 200), alpha=0.8)

# Line plot (with aggregation)
sns.lineplot(data=df, x='year', y='passengers',
             hue='month', style='month', markers=True, dashes=False)

# High-level relplot (returns FacetGrid)
sns.relplot(data=df, x='total_bill', y='tip',
            col='time', row='sex', hue='smoker',
            kind='scatter', height=4, aspect=1.2)

sns.relplot(data=df, x='year', y='passengers',
            kind='line', col='month', col_wrap=4)

6. Distribution Plots

python

               split=True, inner='quartile')

              markers=['o', 's'], linestyles=['-', '--'])

            errorbar='ci', capsize=0.1)

10. Multi-Plot Grids

python
# FacetGrid — core multi-plot object
g = sns.FacetGrid(df, col='time', row='sex', hue='smoker',
                  height=3.5, aspect=1.1, margin_titles=True)
g.map_dataframe(sns.scatterplot, x='total_bill', y='tip')
g.add_legend()
g.set_axis_labels('Total Bill', 'Tip')
g.set_titles(col_template='{col_name}', row_template='{row_name}')

# PairGrid
g = sns.PairGrid(df, hue='sex', vars=['total_bill', 'tip', 'size'])
g.map_diag(sns.histplot, kde=True)
g.map_offdiag(sns.scatterplot, alpha=0.6)
g.add_legend()

# JointGrid
g = sns.JointGrid(data=df, x='total_bill', y='tip', space=0)
g.plot_joint(sns.kdeplot, fill=True, levels=10)
g.plot_marginals(sns.histplot, kde=True)

11. Context & Scaling

python
# Context changes size of labels, lines, etc.
sns.set_context('paper')     # smallest
sns.set_context('notebook')  # default
sns.set_context('talk')      # larger
sns.set_context('poster')    # largest

# Fine-tune
sns.set_context('notebook', font_scale=1.2, rc={'lines.linewidth': 2.5})

# Temporary context
with sns.plotting_context('talk', font_scale=1.1):
    sns.scatterplot(...)

12. Customization & Matplotlib Interop

python
# Most Seaborn functions return a Matplotlib Axes
ax = sns.scatterplot(data=df, x='total_bill', y='tip')
ax.set_title('Custom Title', fontsize=14, color='white')
ax.set_xlabel('Total Bill ($)')
ax.set_facecolor('#1a1b24')

# For FacetGrid / relplot / catplot etc.
g = sns.relplot(...)
g.fig.suptitle('Overall Title', y=1.02)
g.set_titles('Day: {col_name}')
g.tight_layout()

# Access underlying figure
fig = ax.get_figure()
fig.savefig('seaborn_plot.png', dpi=300, bbox_inches='tight')

# Override rcParams for a single plot
with sns.axes_style('darkgrid'), sns.color_palette('muted'):
    sns.boxplot(...)

14. Best Practices

  • Start with sns.set_theme() to get consistent, attractive defaults
  • Prefer the high-level figure-level functions (relplot, displot, catplot, lmplot) when you need faceting
  • Use axes-level functions (scatterplot, histplot, etc.) when you need to place plots on existing Axes or mix with pure Matplotlib
  • Always consider colorblind-friendly palettes (colorblind, viridis, rocket)
  • For large datasets prefer histplot / kdeplot over swarmplot (which can be slow)
  • Combine Seaborn’s statistical power with Matplotlib’s fine control when necessary
  • Document the statistical aggregation (mean, median, CI) you are showing
