1. Introduction to Matplotlib

Matplotlib is the foundational plotting library in Python. It provides a MATLAB-like interface (pyplot) as well as a full object-oriented API. Virtually every other visualization library (Seaborn, Pandas plotting, Plotly wrappers, etc.) builds on or interoperates with Matplotlib.

Key Concepts

  • Figure — the overall window or page
  • Axes — an individual plot (a Figure can contain multiple Axes)
  • Artist — everything visible (lines, text, patches…)
  • Two coding styles: pyplot state-machine and explicit object-oriented

3. The Two Interfaces

Pyplot (state-based) — convenient for quick plots

python
plt.plot([1, 2, 3, 4], [1, 4, 9, 16])
plt.title('Simple Plot')
plt.xlabel('x')
plt.ylabel('y')
plt.show()

Object-oriented — preferred for complex figures

python
fig, ax = plt.subplots()
ax.plot([1, 2, 3, 4], [1, 4, 9, 16])
ax.set_title('Simple Plot')
ax.set_xlabel('x')
ax.set_ylabel('y')
plt.show()

5. Line Plots

python
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

fig, ax = plt.subplots()

9. Customization Deep Dive

python
fig, ax = plt.subplots(figsize=(9, 5))

# Titles & labels
ax.set_title('Main Title', fontsize=16, fontweight='bold', color='white', pad=15)
ax.set_xlabel('X Axis', fontsize=12)
ax.set_ylabel('Y Axis', fontsize=12)

# Limits & ticks
ax.set_xlim(0, 10)
ax.set_ylim(-1.5, 1.5)
ax.set_xticks([0, 2, 4, 6, 8, 10])
ax.set_xticklabels(['0', '2', '4', '6', '8', '10'], rotation=45)
ax.tick_params(axis='both', labelsize=10, colors='#848B9E')

# Spines
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.spines['left'].set_color('#848B9E')
ax.spines['bottom'].set_color('#848B9E')

# Grid
ax.grid(True, linestyle='--', alpha=0.3, color='#848B9E')
ax.set_axisbelow(True)

# Legend
ax.legend(loc='upper right', frameon=False, fontsize=10)

# Text & annotations
ax.text(5, 1, 'Important point', fontsize=11, color='#D95B83')
ax.annotate('Peak', xy=(1.57, 1), xytext=(3, 1.2),
            arrowprops=dict(arrowstyle='->', color='#B8C5F2'))

# Background
ax.set_facecolor('#1a1b24')
fig.patch.set_facecolor('#12131A')

10. Subplots & Layouts

15. Best Practices

  • Prefer the object-oriented API for anything beyond a quick exploration plot
  • Always label axes and provide a clear title or caption
  • Use colorblind-friendly colormaps (viridis, plasma, cividis)
  • Avoid chartjunk — maximize data-ink ratio
  • Set figsize and dpi intentionally for the target medium (screen vs print)
  • Close figures when creating many of them in a loop (plt.close(fig))
  • For statistical plots consider Seaborn first — it handles many aesthetics automatically
