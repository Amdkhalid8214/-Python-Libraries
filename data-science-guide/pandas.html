1. Introduction to Pandas

Pandas is the de-facto library for data manipulation and analysis in Python. It introduces two primary data structures: Series (1-dimensional labeled array) and DataFrame (2-dimensional labeled data structure). Built on NumPy, it adds labels, flexible indexing, handling of missing data, and powerful group-by / reshape operations.

Core Strengths

  • Labeled axes (rows & columns) for intuitive data access
  • Automatic and explicit data alignment
  • Robust handling of missing data
  • Powerful group-by, merge and reshape tools
  • Time-series functionality
  • Flexible I/O for CSV, Excel, SQL, JSON, Parquet, etc.

bash
pip install pandas
python
import pandas as pd

3. Series

A Series is a one-dimensional labeled array capable of holding any data type.

python
# From list
s = pd.Series([10, 20, 30, 40], index=['a', 'b', 'c', 'd'])
print(s)

# From dict
s2 = pd.Series({'x': 1, 'y': 2, 'z': 3})

# From NumPy
s3 = pd.Series(np.random.randn(5), name='returns')

# Attributes
s.values, s.index, s.dtype, s.name, s.shape

Indexing a Series

python
s['a']              # label
s[0]                # position (avoid when labels are integers)
s.loc['a']          # label-based (preferred)
s.iloc[0]           # position-based
s[['a', 'c']]       # multiple labels
s[s > 20]           # boolean filtering

4. DataFrame

A DataFrame is a 2-D labeled data structure with columns of potentially different types — like a spreadsheet or SQL table.

python
# From dict of lists / arrays
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Charlie'],
    'age': [25, 30, 35],
    'city': ['NY', 'LA', 'Chicago']
})

# From list of dicts
df2 = pd.DataFrame([
    {'name': 'Alice', 'age': 25},
    {'name': 'Bob', 'age': 30}
])

# From NumPy array
df3 = pd.DataFrame(np.random.randn(4, 3),
                   columns=['A', 'B', 'C'],
                   index=['r1', 'r2', 'r3', 'r4'])

print(df.head())
print(df.info())
print(df.describe())
print(df.dtypes)
print(df.shape)
print(df.columns)
print(df.index)

5. Reading & Writing Data

python

6. Indexing, Selection & Filtering

python
# Column selection
df['age']                 # Series
df[['name', 'age']]       # DataFrame

# Label-based (.loc)
df.loc[0]                 # row by label
df.loc[0, 'name']
df.loc[0:2, ['name', 'age']]
df.loc[df['age'] > 28]

# Position-based (.iloc)
df.iloc[0]
df.iloc[0:2, 0:2]
df.iloc[[0, 2], [0, 2]]

# Boolean filtering
df[(df['age'] > 25) & (df['city'] == 'NY')]
df.query('age > 25 and city == "NY"')

# Setting values
df.loc[0, 'age'] = 26
df['salary'] = [50000, 60000, 70000]   # new column

Index objects

python
df.set_index('name', inplace=True)
df.reset_index(inplace=True)
df.reindex(['a', 'b', 'c'])
df.sort_index(ascending=False)
df.sort_values('age', ascending=False)

7. Handling Missing Data

python
# Detection
df.isna()                 # or df.isnull()
df.notna()
df.isna().sum()

# Dropping
df.dropna()               # rows with any NaN
df.dropna(axis=1)         # columns
df.dropna(how='all')      # only if all values NaN
df.dropna(subset=['age'])
df.dropna(thresh=2)       # keep rows with ≥2 non-NaN

# Filling
df.fillna(0)
df.fillna({'age': df['age'].mean(), 'city': 'Unknown'})
df.fillna(method='ffill') # forward fill (deprecated → ffill())
df.ffill()
df.bfill()
df.interpolate()          # linear interpolation

# Replacing
df.replace(-999, np.nan)
df.replace({'old': 'new'})

8. Operations & Functions

python
# Arithmetic (aligns on index/columns)
df['age'] + 5
df['age'] * df['salary']

# Apply / map / applymap
df['age'].map(lambda x: x + 1)
df.apply(np.sqrt)                     # column-wise by default
df.apply(lambda x: x.max() - x.min())
df.applymap(lambda x: f'{x:.2f}')     # element-wise (deprecated → map)

# String methods
df['name'].str.upper()
df['name'].str.contains('A')
df['name'].str.split(' ').str[0]

# Aggregation
df['age'].mean()
df.agg(['mean', 'std', 'min', 'max'])
df.describe(include='all')

9. GroupBy & Aggregation

The split-apply-combine pattern is one of Pandas’ most powerful features.

python
df.groupby('city')['age'].mean()
df.groupby('city').agg({'age': 'mean', 'salary': ['sum', 'count']})

# Multiple keys
df.groupby(['city', 'department']).mean()

# Transformation (same shape as original)
df['age_z'] = df.groupby('city')['age'].transform(
    lambda x: (x - x.mean()) / x.std()
)

# Filter groups
df.groupby('city').filter(lambda g: g['age'].mean() > 30)

# Iteration
for name, group in df.groupby('city'):
    print(name, group.shape)

# Named aggregation (modern)
df.groupby('city').agg(
    avg_age=('age', 'mean'),
    total_salary=('salary', 'sum')
)

10. Merge, Join & Concatenation

python
# Concatenation
pd.concat([df1, df2], axis=0, ignore_index=True)
pd.concat([df1, df2], axis=1)
pd.concat([df1, df2], keys=['A', 'B'])

# Merge (SQL-style)
pd.merge(left, right, on='key')
pd.merge(left, right, left_on='lkey', right_on='rkey')
pd.merge(left, right, how='inner')   # inner, left, right, outer, cross
pd.merge(left, right, on='key', suffixes=('_x', '_y'))

# Join (index-based)
left.join(right, how='left')
left.join(right, on='key')

11. Reshaping & Pivot Tables

python
# Pivot
df.pivot(index='date', columns='city', values='temperature')

# Pivot table (with aggregation)
pd.pivot_table(df, values='sales', index='region',
               columns='product', aggfunc='sum', fill_value=0)

# Melt (wide → long)
pd.melt(df, id_vars=['id'], value_vars=['A', 'B'],
        var_name='metric', value_name='value')

# Stack / Unstack
df.stack()
df.unstack()

# Crosstab
pd.crosstab(df['city'], df['department'], margins=True)

12. Time Series

python
# Creating datetime index
dates = pd.date_range('2024-01-01', periods=100, freq='D')
ts = pd.Series(np.random.randn(100), index=dates)

# Conversion
pd.to_datetime(['2024-01-01', '2024/02/15'])
df['date'] = pd.to_datetime(df['date'])

# Indexing
ts['2024-01']
ts['2024-01-01':'2024-01-15']
ts.asof('2024-01-10')

# Resampling
ts.resample('W').mean()
ts.resample('M').sum()
ts.resample('Q').ohlc()

# Shifting & lagging
ts.shift(1)
ts.shift(-1, freq='D')

# Rolling windows
ts.rolling(window=7).mean()
ts.rolling(7).std()
ts.expanding().mean()
ts.ewm(span=10).mean()

# Time zone handling
ts.tz_localize('UTC').tz_convert('US/Eastern')

13. Categorical Data

python
df['city'] = df['city'].astype('category')
df['city'] = pd.Categorical(df['city'],
                            categories=['NY', 'LA', 'Chicago', 'Boston'],
                            ordered=True)

df['city'].cat.categories
df['city'].cat.codes
df['city'].cat.add_categories(['Miami'])
df['city'].cat.remove_unused_categories()
df.sort_values('city')   # respects order if ordered=True

15. Performance Tips

  • Prefer vectorized operations and built-in methods over apply + Python loops
  • Use categorical dtype for repeated string columns
  • Select only needed columns when reading large files (usecols)
  • Use efficient formats: Parquet / Feather instead of CSV for large data
  • Consider eval() / query() for complex expressions on large frames
  • Chain methods carefully; intermediate copies can be costly
  • For very large data explore Dask, Polars or PySpark
